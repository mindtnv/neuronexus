# Полировка интервального обучения — последовательный список

81 проверяемый пункт. `[исправить]` — дефект подтверждён чтением кода; `[доработать]` — согласованное улучшение флоу; `[проверить]` — путь требует ревью, исправление только при найденном дефекте.
